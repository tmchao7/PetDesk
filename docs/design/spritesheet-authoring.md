# 精灵图与姿势图生成指南（在线 AI）

面向豆包 / GPT / Gemini 等在线图像工具。两种用法：

## 用法一：先上传“标准形象”（推荐起点）

让 AI 生成一张**单张全身形象图**，走 Settings → 头像 → 选择图片。应用会自动生成全部 8 行动画（眨眼、呼吸、位移微变换），不需要任何图集知识。

```text
请生成一张全身卡通/动漫风格的小人形象图，正方形构图，人物居中占画面约 70-80%。
要求：Q 版/二头身比例，清晰的轮廓，扁平上色，简单可爱的表情；
纯色背景（或透明背景 PNG）；不要文字、不要水印、不要多余道具。尺寸 1024×1024。
```

## 用法二：为 专注 / 摸鱼 / 休息 各生成一张姿势图

先有头像后，在 Settings → 头像 → 专注姿势 / 摸鱼姿势 / 休息姿势 分别导入。每个状态只需要 **一张图**，该状态的 8 帧动画由应用自动派生；其他状态继续用默认形象。

通用约束（每张都满足）：

- 方形或接近方形构图，人物全身可见、居中；
- 与头像同一个角色：发型、发色、服装、配色保持一致（可在提示词里写死，或用工具的“角色一致性/参考图”功能锁定）；
- 纯色背景或透明背景 PNG（纯色背景应用会自动抠底）；
- 不要文字、水印、网格线、边框、阴影装饰。

专注（工作）姿势：

```text
同一角色，姿势改为：坐在屏幕前认真工作，双手放在键盘上，表情专注，
轻微低头。全身可见，居中，纯色背景，无文字无道具装饰。正方形构图。
```

摸鱼（喝茶）姿势：

```text
同一角色，姿势改为：慵懒地靠在椅背上喝一杯茶，表情放松惬意，微微闭眼。
全身可见，居中，纯色背景，无文字无道具装饰。正方形构图。
```

休息（躺平）姿势：

```text
同一角色，姿势改为：平躺在地上睡觉，眼睛闭着，四肢放松，
表情安详。全身可见，居中，纯色背景，无文字无道具装饰。正方形构图。
```

导入时如提示“姿势图中没有识别到主体”，请换用人物更大、背景更纯的图。

## 进阶：整张 8×8 精灵图

只有当你希望每行是真正的多姿态/自定义帧时才需要（例如用 Codex Pet 工具生成）。规格：1536×1664，8 行 × 8 列，每格 192×208；行序 idle / walking / running / working / drinking / sleeping / happy / surprised；透明背景。在线 AI 直接生成整张图集对齐成功率低，生成后务必用“导入精灵图”校验，失败时按提示重新生成或退回用法一/用法二。
