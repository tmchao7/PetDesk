# 精灵图与姿势图生成指南（在线 AI）

面向豆包 / GPT / Gemini 等在线图像工具。两种用法：

## 用法一：先上传“标准形象”（推荐起点）

让 AI 生成一张**单张全身形象图**，走 Settings → 头像 → 选择图片。应用会自动生成全部 8 行动画（眨眼、呼吸、位移微变换），不需要任何图集知识。

```text
请生成一张全身卡通/动漫风格的小人形象图，正方形构图，人物居中占画面约 70-80%。
要求：Q 版/二头身比例，清晰的轮廓，扁平上色，简单可爱的表情；
纯色背景（或透明背景 PNG）；不要文字、不要水印、不要多余道具。尺寸 1024×1024。
```

## 用法二：为 专注 / 摸鱼 / 休息 各生成一张姿势图

先有头像后，在 Settings → 头像 → 专注姿势 / 摸鱼姿势 / 休息姿势 分别导入。每个状态只需要 **一张图**，该状态的 8 帧动画由应用自动派生；其他状态继续用默认形象。

通用约束（每张都满足）：

- 方形或接近方形构图，人物全身可见、居中；
- 与头像同一个角色：发型、发色、服装、配色保持一致（可在提示词里写死，或用工具的“角色一致性/参考图”功能锁定）；
- 纯色背景或透明背景 PNG（纯色背景应用会自动抠底）；
- 不要文字、水印、网格线、边框、阴影装饰。

专注（工作）姿势：

```text
同一角色，姿势改为：坐在屏幕前认真工作，双手放在键盘上，表情专注，
轻微低头。全身可见，居中，纯色背景，无文字无道具装饰。正方形构图。
```

摸鱼（喝茶）姿势：

```text
同一角色，姿势改为：慵懒地靠在椅背上喝一杯茶，表情放松惬意，微微闭眼。
全身可见，居中，纯色背景，无文字无道具装饰。正方形构图。
```

休息（躺平）姿势：

```text
同一角色，姿势改为：平躺在地上睡觉，眼睛闭着，四肢放松，
表情安详。全身可见，居中，纯色背景，无文字无道具装饰。正方形构图。
```

导入时如提示“姿势图中没有识别到主体”，请换用人物更大、背景更纯的图。

## 进阶：整张 8×8 精灵图

只有当你希望每行是真正的多姿态/自定义帧时才需要（例如用 Codex Pet 工具生成）。规格：1536×1664，8 行 × 8 列，每格 192×208；行序 idle / walking / running / working / drinking / sleeping / happy / surprised；透明背景。在线 AI 直接生成整张图集对齐成功率低，生成后务必用“导入精灵图”校验，失败时按提示重新生成或退回用法一/用法二。

## 用法三：专注状态多帧动画（v0.1.2+）

专注状态支持一次导入最多 **8 张动作帧**，应用按序循环播放，
**播放速度随 CPU 占用率变化**（RunCat 风格：CPU 越高动得越快）。

先在 Settings → 头像 → 专注姿势，**多选** 8 张帧图一次性导入
（PNG/WebP，按文件名顺序排列即可）。

生成方式（豆包）：上传你已有的单张专注姿势图为**参考图**，让它基于
同一角色连续生成 8 个递进动作帧：

```text
请参考我上传的角色图（同一角色，发型/发色/服装/配色完全一致），
为"专注工作"动作生成 8 张连续动作帧，构成一个循环动画。

动作设计（第 1~8 帧）：
1. 双手放键盘，坐直，表情专注，眼睛睁开
2. 身体微微前倾，手指轻敲键盘
3. 低头看键盘，肩膀稍微耸起
4. 抬头看屏幕，嘴巴微张像在思考
5. 眼睛左右移动，像在阅读代码
6. 靠回椅背，手指离开键盘休息半秒
7. 揉揉眼睛，头歪向一侧
8. 坐直双手回键盘（回到第 1 帧的起始姿势，形成无缝循环）

统一要求：
- 每张都是全身可见、居中、正方形构图；
- 角色大小和位置在 8 张中保持一致（只有肢体动作变化，不要整体位移/缩放）；
- 纯色背景（建议纯白或纯绿，应用会自动抠底）；不要文字、水印、网格线；
- 每张尺寸 1024×1024；一次输出 8 张（或分两次各 4 张）；
- 动作幅度适中，帧间差异清晰但不过度夸张。
```

技巧：

- 文件名按播放顺序命名（如 `focus-01.png` … `focus-08.png`），多选时
  按名称排序选择，导入顺序即播放顺序；
- 8 帧可用 5~8 帧，少于 8 帧也行（剩余列自动用默认形象补位）；
- 想让循环更顺滑，让第 8 帧尽量接近第 1 帧的姿势；
- 先导入 8 帧后，Settings 会显示 "×8" 帧数标记；点击宠物 → 专注即可
  看到动画，CPU 越高动画越快（0% CPU ≈ 5 帧/秒，100% CPU ≈ 100 帧/秒）。
