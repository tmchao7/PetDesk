# PetDesk v1 Implementation Plan

> **For agentic workers:** Follow `AGENTS.md`. Use test-first development and keep generated Xcode files untracked.

**Goal:** Deliver a native macOS 26 floating companion driven by public system signals and voluntary focus sessions.

**Architecture:** AppKit owns the floating window, SwiftUI renders the experience, and pure Swift reducers own behavior. Feature adapters isolate system access and degrade independently.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Combine, XCTest/XCUITest, XcodeGen, SwiftPM verification harness.
