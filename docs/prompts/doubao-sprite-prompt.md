# 豆包精灵图生成提示词模板

用豆包（Doubao AI 图片生成）把真人照片变成 PetDesk 桌宠的卡通动画帧。

## 使用流程

三步完成：**照片 → 卡通角色 → 3 个基础状态 → 每组 8 帧动画**

生成后的图片通过 PetDesk 设置 → 头像 → 姿态导入功能导入（专注/摸鱼/休息 各 1~8 帧）。

---

## 第 1 步：照片 → 卡通角色

把一张清晰的真人照片发给豆包，附上以下提示词：

```
请把这张照片中的角色卡通化，生成一张 Q 版卡通/动漫风格的全身立绘图。
要求：
- 全身站立，正面朝向，完整露出头部、身体、四肢
- 保留照片中人物的显著特征（发型、发色、服装配色、配饰）
- Q 版比例（头身比约 1:2.5~1:3）
- 纯绿色背景（#00FF00），角色本身不要使用绿色
- 单张角色图，画面居中，脚下留一点空间
- 图片尺寸建议 1024×1024
```

保存生成结果，作为第 2 步的参考图。

---

## 第 2 步：卡通角色 → 3 个基础状态

把第 1 步的卡通角色图发给豆包，生成 3 张基础状态图（一次一张，或要求横向三格）：

```
请基于这张卡通角色参考图，保持角色完全一致（发型、服装、配色、比例），
生成以下 3 个状态各一张全身图：

1. 【专注】坐在电脑桌前，双手放在键盘上，认真工作
2. 【摸鱼】坐在椅子上，单手端着一杯茶，悠闲放松
3. 【休息】趴在桌边睡觉，眼睛闭着，神情放松

要求：
- 每张都是完整全身，Q 版比例与参考图一致
- 纯绿色背景（#00FF00）
- 每个状态单独一张图，居中
```

---

## 第 3 步：基础状态 → 每组 8 帧动画

对每个基础状态图，分别使用下面 3 组提示词，每组生成 **8 帧连续动作**（一次生成一张横向长图，8 帧从左到右排列，动作连贯，像动漫原画帧）。

### 组 1：专注（工作循环）

```
请基于这张【专注】状态的角色图，生成 8 帧横向排列的连续动画帧，
动作依次为（从左到右）：
1. 坐直身体，双手放在键盘上
2. 右手食指按下键盘
3. 双手开始有节奏地敲击键盘
4. 敲击加快，身体微微前倾
5. 快速连续敲击，屏幕光映在脸上
6. 短暂停顿，手离开键盘
7. 抬手擦一下额头
8. 回到坐直姿势，准备下一轮

要求：
- 每帧都是同一个角色的全身或半身工作姿势
- 8 帧动作连贯，循环播放时第 8 帧能自然接回第 1 帧
- 纯绿色背景（#00FF00），角色不要使用绿色
- 8 帧横向等距排列，每帧大小一致
```

### 组 2：摸鱼（喝茶循环）

```
请基于这张【摸鱼】状态的角色图，生成 8 帧横向排列的连续动画帧，
动作依次为（从左到右）：
1. 端正坐好，茶杯放在桌上
2. 伸手端起茶杯
3. 把茶杯举到嘴边
4. 闭眼抿一小口，神情满足
5. 慢慢放下茶杯
6. 转头左右看看，确认没人
7. 偷笑着缩回脖子，一脸得意
8. 回到端正坐姿，准备下一轮

要求：
- 每帧都是同一个角色的喝茶姿势
- 8 帧动作连贯，循环播放时第 8 帧能自然接回第 1 帧
- 纯绿色背景（#00FF00），角色不要使用绿色
- 8 帧横向等距排列，每帧大小一致
```

### 组 3：休息（入睡循环）

```
请基于这张【休息】状态的角色图，生成 8 帧横向排列的连续动画帧，
动作依次为（从左到右）：
1. 坐直，抬手打一个哈欠
2. 揉揉眼睛，眼皮开始变重
3. 身体慢慢向前趴
4. 趴到桌上，闭眼
5. 完全睡着，头顶冒出一个小 Zzz
6. 熟睡，Zzz 变大，身体微微起伏
7. 翻了个身换个姿势继续睡
8. 仍然睡着，呼吸平稳，准备循环

要求：
- 每帧都是同一个角色的睡觉姿势
- 8 帧动作连贯，循环播放时第 8 帧能自然接回第 1 帧
- 纯绿色背景（#00FF00），角色不要使用绿色
- 8 帧横向等距排列，每帧大小一致
```

---

## 输出规格（所有图片通用）

| 项目 | 要求 |
|---|---|
| 单帧尺寸 | 192×208 px（竖构图） |
| 背景 | 纯绿 #00FF00（方便 PetDesk 自动去背） |
| 排列 | 8 帧横向一行，等距，帧间无空隙 |
| 一致性 | 同角色、同画风、同配色、同比例 |
| 循环 | 第 8 帧能自然接回第 1 帧（无缝循环） |

> 豆包可能不会严格输出 192×208 的每帧尺寸，没关系——PetDesk 导入时会自动去绿幕、裁切并对齐到标准帧。只要保证：绿背景、8 帧横向排列、动作连贯即可。

---

## 导入 PetDesk

1. 打开 PetDesk 设置 → 头像 → 姿态导入
2. 依次为「专注」「摸鱼」「休息」选择对应生成的 8 帧长图
3. PetDesk 自动去绿幕、切帧、组装进精灵图
4. 宠物在对应状态时就会播放你生成的动画帧（速度随 CPU 变化，可在设置里调动画速度）

## 常见问题

- **角色不一致**：如果豆包生成的帧角色走样，把第 2 步的角色图作为参考图重新强调"保持完全一致"，必要时分帧重生成。
- **绿背景没去掉**：确认角色本身没有大面积的绿色（衣服/皮肤不能是绿色）。
- **帧数不足 8**：豆包有时只给 4~6 帧，PetDesk 支持每行 1~8 帧，少于 8 帧也能用（不足的列自动用基准帧补位）。
