# ADR 0003: Notification Integration May Be Unsupported

## Status

Accepted on 2026-07-30.

There is no stable public source-app notification feed for third-party macOS apps. The v1 integration reports unsupported and does not request Accessibility permission. Future work may activate the existing adapter only when it can identify WeChat or QQ without retaining content. OCR, private databases, and private APIs remain forbidden.
